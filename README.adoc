= CityCare - Digitale Meldestelle für städtische Mängel

== Über das Projekt
CityCare ist eine Webplattform, die es Bürgern ermöglicht, städtische Mängel wie kaputte Straßen, defekte Laternen oder Vandalismus einfach und schnell zu melden. Die Plattform erleichtert die Kommunikation mit der Stadtverwaltung und trägt dazu bei, Probleme effizienter zu lösen.

== Ziel des Projekts
Unser Hauptziel ist es, die Lebensqualität der Bürger zu verbessern, indem Probleme schneller erkannt und behoben werden. Dadurch wird die Stadtverwaltung entlastet und die Zufriedenheit der Einwohner gesteigert.
