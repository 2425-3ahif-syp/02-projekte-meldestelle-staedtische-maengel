== Pflichtenheft

=== Beschreibung der Ausgangslage

==== Ist-Zustand
Aktuell werden Mängel in einer Gemeinde meistens telefonisch oder über Briefe bei der Stadtverwaltung gemeldet. Diese Methode erschwert es den Bürgern, ein Problem zu melden, was die Motivation verringern kann. Mängel bleiben so oft unentdeckt oder werden zu spät oder gar nicht gelöst.

==== Problemstellung

Die Meldung städtischer Mängel erfolgt oft über umständliche Wege (Telefon, E-Mail), was zu:

* Verzögerter Bearbeitung von Problemen
* Mangelnder Transparenz für Bürger
* Ineffizienter Verwaltung der Meldungen

führt.

==== Aufgabenstellung

Eine digitale Plattform soll entwickelt werden, die:

* Einfache Erfassung von Mängeln mit Foto und Standort ermöglicht
* Den Bearbeitungsstatus erfasst
* Die Verwaltung und Bearbeitung der Meldungen regelt

==== Zielsetzung
Ziel ist es, eine Plattform zu entwickeln, auf der Bürger Mängel in ihrer Gemeinde melden können. Die Meldungen sollen automatisch an die zuständige Gemeinde weitergeleitet werden, um Probleme schnellstmöglich zu lösen. Die Plattform wird benutzerfreundlich und einfach zu bedienen sein.

== Anforderungen (Soll)

=== Funktionale Anforderungen

===== Meldung von Mängeln
- Nutzer können Mängel über ein Formular melden (Beschreibung, Standort via GPS oder manuell, Foto).
- Meldungen werden kategorisiert (z.B. Straßen, Beleuchtung, Müll).
- Möglichkeit zur Registrierung oder Login mit Email und Passwort.

===== Datenverwaltung
- Nutzer können den Fortschritt der Meldung verfolgen.
- Automatische Benachrichtigungen per E-Mail bei Statusänderungen.
- Meldungen werden automatisch an die zuständige Gemeinde weitergeleitet.
- Verwaltung kann den Status der Meldung ändern und das Problem lösen.

=== Nicht-funktionale Anforderungen

===== Benutzerfreundlichkeit
- Ansprechendes Design und einfache Nutzung, auch für technisch weniger versierte Nutzer.

===== Technische Anforderungen
- Webserver (z.B. über Github Pages) für Hosting, der Sicherheits- und Performanceanforderungen erfüllt.
- Datenbank zur Speicherung der Meldungen, die sicher und zuverlässig aufgesetzt wird.

=== Mengengerüst

==== Anzahl der Benutzer
- Erwartet wird, dass 15% der Benutzer die Plattform nutzen werden. Die meisten kommen vermutlich aus Oberösterreich.

==== Anzahl der Meldungen
- Es wird erwartet, dass die Plattform mindestens 50 Meldungen pro Monat erhält.
